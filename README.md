# Trabajos prácticos — Soporte (UTN FRRo)

Prácticas de la electiva de Soporte, en Python.

| Carpeta | Qué es |
|---|---|
| `opencv-final/` | Detector de lugares libres en un estacionamiento a partir de video: calibración, autodetección de celdas, estabilización de imagen, tests y dashboard |
| `conteo-opencv/` | Conteo de objetos en video con OpenCV |
| `Aruco/` | Generación y detección de marcadores ArUco |
| `flask/` | Ejercicios de Flask: rutas, parámetros, plantillas Jinja2 y formularios |
| `gtts/` | App web de texto a voz (gTTS) |
| `stt/` | Reconocimiento de voz a texto |
| `genai/` | Pruebas con un modelo de IA generativa |
| `calculadora-kyvy/` | Calculadora con interfaz Kivy |

## Entorno
```bash
uv sync
```
En `gtts/`, los certificados para HTTPS local se generan aparte (no están versionados).
